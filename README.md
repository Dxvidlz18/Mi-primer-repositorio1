Calculadora de Áreas y Perímetros

Este proyecto contiene funciones en Python para calcular el área y el perímetro de diferentes figuras geométricas (cuadrado, rectángulo, círculo, triángulo y rombo).

Funcionalidades:
- Cálculo de área y perímetro para figuras planas.
- Entradas interactivas por consola.


 Lenguaje utilizado
- Python 3
